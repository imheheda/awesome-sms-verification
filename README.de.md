## Was ist SMS-Verifizierung?

SMS empfangen — auch bekannt als SMS online erhalten, Nutzung einer *virtuellen Nummer* oder einer *Wegwerfnummer* — ermöglicht dir, einen einmaligen Bestätigungscode zu erhalten, **ohne deine persönliche SIM-Karte zu verwenden**. Du mietest für kurze Zeit eine echte Mobilfunknummer: lang genug, um die SMS zu empfangen und eine Registrierung oder einen Schritt der Zwei-Faktor-Authentifizierung (2FA) abzuschließen, danach wird sie freigegeben.

Üblicherweise wird das verwendet für:

- Registrierung bei Apps, die eine Telefonnummer verlangen (Telegram, WhatsApp, Instagram, TikTok…)
- Empfang von 2FA- / OTP-Codes für Krypto-Börsen, E-Mail und andere Konten
- Trennung von Arbeits-, Test- und privaten Konten auf verschiedene Nummern
- Schutz deiner Privatsphäre, indem du nicht jede Registrierung mit einer einzigen Identität verknüpfst

## Wie man einen SMS-Code empfängt

Am Beispiel von [jiema.my](https://jiema.my/de):

1. Wähle den Dienst, den du verifizierst (Telegram, WhatsApp, Google…), und ein Land.
2. Gib die Bestellung auf — die temporäre Nummer erscheint sofort auf deiner Bestellseite.
3. Gib diese Nummer auf der Plattform ein und löse den SMS-Versand aus.
4. Der Bestätigungscode trifft innerhalb von Sekunden auf deiner Bestellseite ein. Kopiere ihn — fertig.

## FAQ

**Ist es legal, einen SMS-Code online zu empfangen?**
Eine Bestätigungs-SMS zu empfangen ist in praktisch jedem Land legal — du mietest die kurzfristige Nutzung einer echten Nummer. Ob du mehrere Konten auf einer bestimmten Plattform eröffnen darfst, regeln die Nutzungsbedingungen dieser Plattform, nicht die Nummer selbst.

**Wie lange behalte ich die Nummer?**
Üblicherweise ist eine einzelne SMS-Bestellung ~15 Minuten aktiv. Auf [jiema.my](https://jiema.my/de) wird die Bestellung automatisch storniert und dein Guthaben erstattet, falls in diesem Fenster kein Code eintrifft.

**Kann ich dieselbe Nummer wiederverwenden?**
Nein. Sobald eine Nummer ein Konto bei einem Dienst verifiziert hat, markiert dieser Dienst sie als verwendet. Jede Verifizierung benötigt eine neue Nummer.

**Welcher ist am günstigsten?**
[jiema.my](https://jiema.my/de) beginnt bei $0.05 pro Code mit im Voraus angezeigten Preisen und lässt dich Live-Preise ohne Registrierung prüfen.
