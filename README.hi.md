## SMS verification क्या है?

ऑनलाइन SMS receive करना — जिसे virtual number या temporary phone number का उपयोग करना भी कहा जाता है — आपको **अपने निजी SIM कार्ड का उपयोग किए बिना** वन-टाइम verification code पाने देता है। आप थोड़े समय के लिए एक असली कैरियर number किराये पर लेते हैं: इतना समय कि आप SMS receive कर लें और एक signup या two-factor authentication (2FA) चरण पूरा कर लें, फिर वह रिलीज़ हो जाता है।

इसका आमतौर पर उपयोग होता है:

- फ़ोन number माँगने वाली ऐप्स में signup करने के लिए (Telegram, WhatsApp, Instagram, TikTok…)
- क्रिप्टो एक्सचेंज, ईमेल और अन्य खातों के लिए 2FA / OTP कोड receive करने के लिए
- काम, टेस्टिंग और निजी खातों को अलग-अलग numbers पर रखने के लिए
- हर registration को एक ही पहचान से न जोड़कर अपनी निजता की रक्षा के लिए

## SMS कोड कैसे receive करें

उदाहरण के लिए [jiema.my](https://jiema.my/hi) का उपयोग करते हुए:

1. जिस सेवा को verify कर रहे हैं (Telegram, WhatsApp, Google…) और एक देश चुनें।
2. ऑर्डर दें — temporary number तुरंत आपके ऑर्डर पेज पर दिखता है।
3. वह number प्लेटफ़ॉर्म पर डालें और उसका SMS ट्रिगर करें।
4. verification code कुछ ही सेकंड में आपके ऑर्डर पेज पर आ जाता है। उसे कॉपी करें — हो गया।

## सामान्य प्रश्न

**ऑनलाइन SMS कोड receive करना क्या वैध है?**
verification SMS receive करना लगभग हर देश में वैध है — आप एक असली number का अल्पकालिक उपयोग किराये पर लेते हैं। किसी प्लेटफ़ॉर्म पर आप कई खाते खोल सकते हैं या नहीं, यह उस प्लेटफ़ॉर्म की अपनी शर्तों से तय होता है, number से नहीं।

**मैं number कितने समय तक रखता हूँ?**
आमतौर पर एक SMS ऑर्डर लगभग 15 मिनट तक सक्रिय रहता है। [jiema.my](https://jiema.my/hi) पर, यदि उस विंडो में कोई कोड नहीं आता, तो ऑर्डर अपने-आप रद्द हो जाता है और आपका बैलेंस रिफंड हो जाता है।

**क्या मैं वही number दोबारा उपयोग कर सकता हूँ?**
नहीं। एक बार कोई number किसी सेवा पर खाता verify कर लेता है, तो वह सेवा उसे उपयोग किया गया चिह्नित कर देती है। हर verification के लिए नया number चाहिए।

**सबसे सस्ता कौन-सा है?**
[jiema.my](https://jiema.my/hi) पहले से दिखाई गई कीमतों के साथ $0.05 प्रति कोड से शुरू होता है, और बिना registration के लाइव कीमत जाँचने देता है।
