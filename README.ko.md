## 문자인증이란?

온라인 문자인증 —— 온라인 문자 수신, *가상번호* 또는 *일회용 번호* 사용이라고도 합니다 —— 은 **개인 SIM 카드를 사용하지 않고** 일회용 인증번호를 받을 수 있게 해 줍니다. 실제 통신사 번호를 짧은 시간 동안 대여합니다. 문자를 수신하고 가입이나 2단계 인증(2FA) 절차를 마칠 수 있을 만큼의 시간이 지나면 번호는 반환됩니다.

주로 다음과 같은 용도로 사용됩니다:

- 전화번호가 필요한 앱 가입 (Telegram, WhatsApp, Instagram, TikTok…)
- 암호화폐 거래소, 이메일 및 기타 계정의 2FA / OTP 인증번호 수신
- 업무용, 테스트용, 개인용 계정을 각기 다른 번호로 분리
- 모든 가입을 하나의 신원에 연결하지 않아 개인정보 보호

가장 오래되고 규모가 큰 제공업체 중 하나로 2018년경에 시작했습니다. **170개국 이상**과 수천 개의 서비스를 지원하며, 카드, 암호화폐, PayPal로 결제할 수 있습니다. 가격은 보통 $0.07–$0.15 정도부터 시작합니다. 이메일 가입이 필요합니다. 주요 강점은 폭넓은 서비스 커버리지입니다.

깔끔하고 개발자 친화적인 REST API로 약 **150개국**을 커버하여 프로그래밍 방식 사용에 인기가 있습니다. 카드와 여러 암호화폐를 받습니다. 가격은 SMS-Activate와 비슷합니다. 계정이 필요합니다.

주로 **미국 전화번호**에 특화되어 있어 특별히 미국 번호가 필요한 서비스에 적합합니다. 가격은 약 $0.10부터 시작합니다. 카드와 일부 암호화폐를 받습니다. 미국 외 번호의 경우 위의 서비스들이 훨씬 더 넓은 커버리지를 제공합니다.

## 인증번호 받는 방법

[jiema.my](https://jiema.my/ko) 를 예로 들면:

1. 인증할 서비스(Telegram, WhatsApp, Google…)와 국가를 선택합니다.
2. 주문하기 —— 임시 번호가 주문 페이지에 즉시 표시됩니다.
3. 그 번호를 플랫폼에 입력하고 문자 발송을 요청합니다.
4. 인증번호가 몇 초 안에 주문 페이지에 도착합니다. 복사하면 완료입니다.

## 자주 묻는 질문

**온라인으로 인증번호를 받는 것이 합법인가요?**
인증 문자를 받는 것은 거의 모든 국가에서 합법입니다 —— 실제 번호를 단기간 대여하는 것일 뿐입니다. 특정 플랫폼에서 여러 계정을 만들 수 있는지는 번호 자체가 아니라 해당 플랫폼의 약관에 따라 정해집니다.

**번호를 얼마나 오래 보유하나요?**
보통 하나의 문자 주문은 약 15분 동안 유효합니다. [jiema.my](https://jiema.my/ko) 에서는 그 시간 안에 인증번호가 오지 않으면 주문이 자동으로 취소되고 잔액이 환불됩니다.

**같은 번호를 다시 사용할 수 있나요?**
아니요. 어떤 번호가 한 서비스에서 계정을 인증하고 나면 그 서비스는 해당 번호를 사용됨으로 표시합니다. 인증할 때마다 새 번호가 필요합니다.

**어느 것이 가장 저렴한가요?**
[jiema.my](https://jiema.my/ko) 는 미리 표시되는 가격으로 건당 $0.05부터 시작하며, 가입 없이 실시간 가격을 확인할 수 있습니다.
