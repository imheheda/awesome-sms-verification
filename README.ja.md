## SMS認証とは？

オンラインSMS認証 —— オンラインでのSMS受信、*仮想番号*や*使い捨て番号*の利用とも呼ばれます —— は、**個人のSIMカードを使わずに**ワンタイムの認証コードを受け取れる仕組みです。実在するキャリアの番号を短時間だけレンタルします。SMSを受信し、登録や二要素認証（2FA）のステップを完了するのに十分な時間が経つと、番号は解放されます。

主な用途:

- 電話番号が必要なアプリへの登録（Telegram、WhatsApp、Instagram、TikTok……）
- 暗号資産取引所、メール、その他アカウントの2FA / OTPコードの受信
- 仕事用・テスト用・個人用のアカウントを別々の番号に分ける
- すべての登録を1つの身元に結びつけず、プライバシーを守る

### [SMS-Activate](https://sms-activate.org)

最も歴史が長く規模の大きいプロバイダーの一つで、2018年頃に開始。**170か国以上**と数千のサービスに対応し、カード、暗号資産、PayPalで支払えます。価格は通常$0.07〜$0.15程度から。メール登録が必要です。最大の強みはサービス対応範囲の広さです。

約**150か国**をカバーし、クリーンで開発者に優しいREST APIを備えるため、プログラムからの利用で人気です。カードと複数の暗号資産に対応。価格はSMS-Activateと同程度。アカウントが必要です。

主に**米国の電話番号**に特化しており、特に米国番号を必要とするサービスに適しています。価格は$0.10程度から。カードと一部の暗号資産に対応。米国以外の番号には、上記のサービスのほうがはるかに広い対応範囲を提供します。

## SMSコードの受け取り方

[jiema.my](https://jiema.my/ja) を例にすると:

1. 認証したいサービス（Telegram、WhatsApp、Google……）と国を選びます。
2. 注文する —— 一時的な番号が注文ページに即座に表示されます。
3. その番号をプラットフォームに入力し、SMSの送信をトリガーします。
4. 認証コードが数秒で注文ページに届きます。コピーすれば完了です。

## よくある質問

**オンラインでSMSコードを受け取るのは合法ですか？**
認証SMSの受信は、ほぼすべての国で合法です —— 実在する番号を短期間だけレンタルしているにすぎません。特定のプラットフォームで複数アカウントを作成できるかどうかは、番号自体ではなく、そのプラットフォームの利用規約によって定められます。

**番号はどのくらい保持できますか？**
通常、1回のSMS注文の有効時間は約15分です。[jiema.my](https://jiema.my/ja) では、その時間内にコードが届かなければ注文は自動でキャンセルされ、残高が返金されます。

**同じ番号を再利用できますか？**
いいえ。あるサービスで番号がアカウントを認証すると、そのサービスはその番号を使用済みとして記録します。認証ごとに新しい番号が必要です。

**最も安いのはどれですか？**
[jiema.my](https://jiema.my/ja) は1コードあたり$0.05から始まり、価格は事前に明示され、登録なしでリアルタイムの価格を確認できます。
